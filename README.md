Tiping Game is a game/tool that is very similar to other typing tests, but for your calculator! 
Designed for the TI-84 Plus CE Python edition calculator, but will most likely work on other calculators that support Python.

If you don't know how to transfer files onto your calculator, I recommend this tutorial: 
https://www.youtube.com/watch?v=xNrbqKDMNko

Enjoy :D
